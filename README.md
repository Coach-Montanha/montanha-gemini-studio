# Montanha Gemini Studio

Assistente de IA moderno com visual estilo Google Gemini, múltiplos chats isolados (Graphify ready), geração de imagens sem limites e análise multimodal com zero custo de tokens locais.

## Recursos
- **Zero Custo de Tokens**: Conectado à API oficial gratuita do Google Gemini (`gemini-flash-lite-latest`).
- **Múltiplos Chats com Contexto Isolado**: Cada conversa possui memória própria.
- **Geração de Imagens**: Motor Flux/Turbo integrado em alta resolução (1024x1024).
- **Leitura de PDFs**: Ingestão e extração de capítulos de livros e artigos.
- **Voz Neural**: Síntese de fala brasileira em MP3.
- **Cloud Ready**: Totalmente compatível com Vercel Serverless.
